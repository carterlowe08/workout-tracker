# Workout Tracker

A mobile-friendly workout tracker: build workouts from about 780 exercises and
log them set by set with a rest timer, track calories eaten and burned with
macros, follow a nutrition plan, and keep a gym streak with RPE.

**Try it:** https://carterlowe08.github.io/workout-tracker/

Your data is saved only in your own browser.

Built by Carter Lowe for CS 124 at the University of Illinois. This repository is
published automatically from the project; changes are made there, not here.
